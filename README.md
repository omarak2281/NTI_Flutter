# To Do App 

## Overview
A Flutter to-do list app with task management, login/register screens, and profile features.

## Setup Instructions
1. Clone the repo: `git clone https://github.com/omarak2281/NTI_Flutter.git`
2. Checkout the branch: `git checkout to-do-app-submission`
3. Install dependencies: `flutter pub get`
4. Run the app: `flutter run` 

## Features
- Login/Register with form validation
- Task creation/editing with Lexend Deca font
- Profile screen with avatar
- Assets in `assets/images/` (e.g., palestine_flag.png)

## Notes
- Uses Lexend Deca and Montserrat fonts (in `pubspec.yaml`).
- Debug banner disabled.
